# Bookings

`/book/` is a multi-step service enquiry form. It collects service, property, size, preferred schedule, location, customer details, notes, and payment preference, then submits an enquiry. It does not reserve a slot, calculate an authoritative price, create a booking number, take payment, or confirm availability.

A real booking workflow requires a Core API, service catalog, availability rules, database state transitions, staff assignment, notifications, cancellation/refund policy, and authenticated customer access.
