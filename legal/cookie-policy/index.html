not assumed.

This website uses a limited consent model. Necessary cookies are enabled by default. Optional categories remain off until a user explicitly grants consent.

What we use

Four categories.

Necessary: session, security, accessibility and basic site functionality.

Preferences: language, theme, and saved UI settings when users choose to store them.

Analytics: only if a future analytics provider is approved and consented to by the user.

Marketing: not activated by default and not used without a valid consent record.

Consent

Granular and reversible.

Users may accept all, reject optional categories, or change preferences later from the site footer or this policy page. Consent is stored with the date, version and selected categories to support compliance and user control.

FreClean does not install marketing or analytics scripts before valid consent where local law requires consent. Optional tracking is never treated as implied permission.
